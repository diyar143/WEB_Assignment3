Objective:

The objective of this assignment is to learn how to create responsive web layouts using CSS Media Queries and the Bootstrap Grid system. The project covers responsive typography, layout re-arrangement using breakpoints, utilizing Bootstrap's 12-column grid, responsive navigation bars, and combining both techniques into a fully functional Volleyball Nations League (VNL) 2026 hub.

---

Part 1: Media Queries

Task 0: Responsive Typography
Implemented responsive font sizing using CSS media queries for the VNL 2026 title and subtitle. Typography scales dynamically across mobile (`<768px`), tablet (`>=768px`), and desktop (`>=992px`) viewports.

Task 1: Responsive Layout with Media Queries
Created a flexbox container displaying three VNL information blocks. Using pure CSS media queries, the layout displays blocks stacked vertically on mobile, two per row on tablet, and all three side-by-side on desktop.

Part 2: Bootstrap Grid System

Task 2: Bootstrap Responsive Columns
Constructed a responsive 3-column tournament grid using Bootstrap's 12-column grid system (`col-12 col-md-6 col-lg-4`). The columns stack on mobile, show two on the top row and one on the second row on tablet, and display as three equal columns on desktop.

Part 3: Combined Project

Task 4: Responsive Portfolio Page
Combined CSS Media Queries and Bootstrap Grid into a unified VNL 2026 Match Hub. The layout includes a dark navigation header, a main content section split into featured match cards (8 columns) and tournament info sidebar (4 columns), custom mobile breakpoints, and a responsive footer.

Summary of Work Process
The project structure was initialized with `index.html` and `style.css`, importing Bootstrap 5 via CDN. Custom media query breakpoints were established to handle responsive font scaling and layout realignment. Bootstrap's grid system and navbar components were integrated to build structured, accessible sections.
